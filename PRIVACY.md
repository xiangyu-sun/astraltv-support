# AstralTV Privacy Policy

AstralTV does not collect, store or transmit any personal data. It has no accounts, analytics, advertising or tracking, and it does not use the network.

| Data | Where stored | Sent to developer? |
|------|-------------|-------------------|
| Personal information | Not collected | No |
| Usage or analytics | Not collected | No |
| Siri Remote input | Used live to move the camera, never stored | No |

Questions: open an issue at https://github.com/xiangyu-sun/astraltv-support/issues
